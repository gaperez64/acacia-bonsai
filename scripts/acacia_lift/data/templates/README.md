# Pinned SYNTCOMP family templates

These 14 TLSF files are byte-for-byte copies from the
[SYNTCOMP benchmarks repository](https://github.com/SYNTCOMP/benchmarks)
at submodule commit `4105caf1f1e5fd3b76657879bfce8021d130cbde` (v2026).
Each file's path below `tlsf/` matches its path below
`tests/syntcomp-benchmarks/` in that commit. The full original path for each
family is recorded as `corpus_source` in `../capabilities-v1.json`; `source`
points to this vendored copy. The SHA-256 pins in that manifest verify the
copies at load time.

The copies have not been modified.
